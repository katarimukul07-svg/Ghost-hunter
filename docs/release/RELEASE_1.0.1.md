# Version 1.0.1 (build 20): rename to Ghost Trail Arcade

Date: Nov 2, 2026. Version 1.0 (build 19) went live on the App Store that morning as "Echo Steps: Ghost Run".

## Why

The owner asked for a shorter name that describes the game. "Echo Steps" and "Ghost Trail" were already taken on the App Store; App Store Connect accepted "Ghost Trail Arcade" and it is saved on the app record for 1.0.1.

## What changes

| Where | Before | After |
|---|---|---|
| App Store name | Echo Steps: Ghost Run | Ghost Trail Arcade |
| Home-screen name (iOS `CFBundleDisplayName`, Capacitor `appName`, Android `app_name`) | Echo Steps | Ghost Trail |
| Main menu heading | ECHO STEPS | GHOST TRAIL |
| Share text and title | ...in Echo Steps! | ...in Ghost Trail Arcade! |
| Web title, manifest, privacy and support pages | Echo Steps | Ghost Trail Arcade |
| Version | 1.0 (build 19) | 1.0.1 (build 20); Android versionName 1.0.1, versionCode 2 |

No gameplay changes. The bundle ID, product IDs, Game Center leaderboard ID, saved progress and the repository name stay the same, so players keep their coins and scores. Internal code names (comments, console logs, `EchoStepsNative`, the ranked client build tag) are unchanged.

## Status

Submitted to App Review on Nov 2, 2026 at 11:12 AM CT (set to release automatically after approval) and live on the App Store on Nov 3, 2026.
